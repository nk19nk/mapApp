# mapApp

Приложение для работы с геолокацией, отображения интерактивной карты, сохранения маркеров с изображениями и получения push-уведомлений при приближении к сохраненным точкам. 
Проект разработан с использованием React Native (Expo SDK 58), TypeScript и локальной базы данных SQLite.

## Инструкция по установке и запуску

1. **Склонируйте репозиторий и установите зависимости:**
   npm install

2. **Запустите сервер разработки Expo:**
   npx expo start -c

3. **Запуск на устройстве:**
   Эмулятор Android: Нажмите a в терминале.
   Физическое устройство: Отсканируйте QR-код через приложение Expo Go (на Android) или камеру (на iOS).

4. **Инструкция по тестированию геолокации и уведомлений**
   1. Создание метки: Долгим нажатием на карту создайте маркер рядом с вашим текущим местоположением.
   2. Симуляция перемещения: На панели эмулятора нажмите на три точки (Extended controls) -> вкладка Location. Задайте координаты на расстоянии более 50 метров от маркера и нажмите Set Location.
   3. Проверка уведомления: В этом же окне задайте координаты максимально близко к сохраненному маркеру и нажмите Set Location. При «входе» в радиус 50 метров появится уведомление «Вы рядом с меткой!».
